PoseGuard Run 2: camera re-run capture

Day 14 capture tool. Records a new validation session with all 33 pose landmarks per frame, longer and deeper holds than Run 1, so the next benchmark can test what the Run 1 data could not. Everything runs on-device in this tab; nothing leaves the machine except the CSV and manifest you download yourself.

How to run this file (Windows, no install)

  1. Download this file from the repo: experiments/rerun-capture.html in github.com/dasarijashwanth/PoseGuard, and save it in a folder by itself, for example C:\poseguard\.
  2. Open PowerShell in that folder and paste this block. It serves the folder on http://localhost:8000/ using the built-in HttpListener. Leave the PowerShell window open while you record.
$listener = New-Object System.Net.HttpListener
$listener.Prefixes.Add("http://localhost:8000/")
$listener.Start()
Write-Host "Serving at http://localhost:8000/ - press Ctrl+C to stop"
while ($listener.IsListening) {
  $ctx = $listener.GetContext()
  $path = $ctx.Request.Url.LocalPath.TrimStart("/")
  if ([string]::IsNullOrEmpty($path)) { $path = "rerun-capture.html" }
  $file = Join-Path (Get-Location) $path
  if (Test-Path $file -PathType Leaf) {
    $bytes = [System.IO.File]::ReadAllBytes($file)
    if ($file -like "*.html") { $ctx.Response.ContentType = "text/html" }
    $ctx.Response.ContentLength64 = $bytes.Length
    $ctx.Response.OutputStream.Write($bytes, 0, $bytes.Length)
  } else {
    $ctx.Response.StatusCode = 404
  }
  $ctx.Response.Close()
}
  1. Open http://localhost:8000/rerun-capture.html in Chrome or Edge. Camera access needs localhost (a secure context); do not open the file directly with file://, the camera will be blocked.
  2. Press Enable camera, allow access, then Start session and follow the prompts. The whole session takes about 8.5 minutes.
  3. At the end, press Download CSV and Download manifest, and send both files back for the re-benchmark.

The protocol (Run 2)

  • Calibration: sit upright and still for 5 s.
  • Head trials: 5 holds, 10 s each, target 15 deg. Get ready 5 s, rest 5 s between holds.
  • Shoulder trials: 5 holds, 10 s each, target 8 deg. Drop one shoulder and hold it. The live bar shows your deviation against the target; tilt deeper until it turns green.
  • Work sample: 5 min of ordinary desk work (typing, mouse, reaching). This is the calm baseline the false-positive check needs.
  • Landmark-loss test: 10 s with the lens covered or out of frame, so the pause-on-loss behaviour is verified.

Why longer and deeper: Run 1 holds moved the shoulder angle only about 2.5 deg while ordinary work drifts 4 to 7 deg, so no threshold could separate them. A 10 s hold gives the 5 s persistence gate real margin, and an 8 deg target sits above the drift band.

Setup checklist

  • Frame yourself from head to hips: shoulders and hips must stay in frame the whole session. If the tool says hips are out of frame, step back from the camera.
  • No bright window or lamp behind you; a backlit silhouette breaks landmark tracking.
  • Wear a plain top with sleeves; bare shoulders and busy patterns confuse the tracker.
  • Keep the camera fixed once you start. Do not move the laptop mid-session.
